# FUTURE_DS_01_Business_Sales_Analytics

## Business Sales Performance Analytics

This project analyzes retail sales transaction data to identify revenue trends, top-performing products, and high-performing markets.

## Objective

The objective is to understand business sales performance and generate actionable insights using data analysis and visualization.

## Tools Used

- Python
- Pandas
- Jupyter Notebook / VS Code
- Power BI

## Key Analysis

- Key Performance Indicators (KPIs)
- Monthly revenue trends
- Top 10 products by revenue
- Top 10 countries by revenue
- Business recommendations

## Data Cleaning

The dataset was cleaned by removing duplicate records, invalid quantities and prices, and cancelled invoices. A Revenue column was created using Quantity × UnitPrice.

## Dashboard

The Power BI dashboard presents the main KPIs, monthly revenue trend, top products, and top countries in an interactive format.

## Dataset Limitation

The dataset does not contain a separate product-category field, so the analysis focuses on individual product performance rather than category-level performance.

## Conclusion

The analysis provides a business-focused view of sales performance and supports decisions related to products, markets, inventory planning, and sales strategy.
